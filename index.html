youtube-bebe

A personal tool that uploads its owner's own videos to the owner's own YouTube channel.

What it is

youtube-bebe is a small command-line program that runs on its owner's personal computer. The owner makes short videos on that computer, and the program uploads them to the owner's YouTube channel as private videos with a scheduled publish time.

It is used by one person, the owner. It is not offered to the public, has no sign-up, and has no other users.

What it does with a Google Account

The owner signs in with Google and grants the program two YouTube permissions:

  • https://www.googleapis.com/auth/youtube.upload — to upload the owner's video files to the owner's channel and set their title, description, and scheduled publish time.
  • https://www.googleapis.com/auth/youtube.readonly — to read the channel's ID and handle before each upload, so that videos go to the intended channel only, and to read the status of the videos the program uploaded.

The program does not edit or delete existing videos, does not read comments or viewers' data, and does not collect information about anyone else.

Where data is kept

The sign-in tokens are stored only in a file on the owner's computer. The program talks only to Google's servers. There is no youtube-bebe server and no database.
