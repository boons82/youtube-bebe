Privacy Policy

youtube-bebe · Effective 10 November 2026

1. Who this covers

youtube-bebe is a personal tool. Its owner runs it on their own computer to upload their own videos to their own YouTube channel. The owner is the only person who signs in to it. It is not offered to the public and has no other users.

2. Google user data the tool accesses

When the owner signs in with Google, the tool asks for two permissions (OAuth scopes) of the YouTube Data API:

  • https://www.googleapis.com/auth/youtube.upload — upload video files to the owner's channel and set their title, description, tags, and scheduled publish time.
  • https://www.googleapis.com/auth/youtube.readonly — read the ID and handle of the channel that granted access, and read the status of the videos the tool uploaded.

The tool does not request any other Google data. It does not access email, contacts, files, comments, subscribers, or viewers' data.

3. How the data is used

  • The upload permission is used only to upload the owner's own videos as private videos with a scheduled publish time.
  • The read-only permission is used only to confirm, before each upload, that the signed-in channel is the intended one, and to check that an uploaded video was processed and scheduled.

The data is not used for advertising, is not sold, and is not used to build profiles or to train artificial-intelligence or machine-learning models.

4. Where the data is stored

The sign-in tokens issued by Google and a short log of the tool's own uploads (video ID and scheduled time) are stored in files on the owner's computer. There is no youtube-bebe server, database, or analytics service. The tool sends data only to Google's API servers.

5. Sharing

The tool does not share, transfer, or disclose Google user data to any third party.

6. Other people's information

The tool does not collect, store, or process personal information about anyone other than its owner.

7. Keeping and deleting data

The tokens stay on the owner's computer until the owner deletes the file or removes the tool's access. Access can be removed at any time in the Google Account settings at myaccount.google.com/connections. After access is removed, the stored tokens no longer work.

8. Google API Services User Data Policy

youtube-bebe's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. YouTube API Services

youtube-bebe uses YouTube API Services. By using the tool, its owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

10. This website

This website is a set of static pages hosted on GitHub Pages. It sets no cookies and runs no tracking of its own. GitHub may log technical information about visits, as described in the GitHub General Privacy Statement.

11. Changes

If this policy changes, the new version will be posted on this page with a new effective date.

12. Contact

Questions about this policy can be sent by opening an issue on GitHub.
